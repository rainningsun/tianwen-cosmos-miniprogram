## 3. 服务类目建议

服务类目取决于**小程序主体**，最终以微信公众平台提交时可选类目和审核要求为准。当前小程序只做图文展示与本地检索，没有视频/直播/支付/登录。

| 主体类型 | 建议类目 | 资质 | 说明 |
|---|---|---|---|
| 个人主体 | 教育服务 → 教育信息展示 | 无 | 仅展示教育信息；不能提供视频播放、直播或课程销售 |
| 高校/公立学校 | 教育服务 → 学历教育（学校） | 教育行政部门审批设立证明或《事业单位法人证书》 | 最适合课程所属高校；如后续增加视频/直播，再补“在线视频课程” |
| 民办学校/培训机构 | 教育服务 → 学历教育（培训机构） | 《民办学校办学许可证》+ 营业执照/事业单位法人证书/民办非企业登记证书 | 仅在有相应办学资质时选择 |
| 其他企业主体 | 先与平台确认“教育信息展示/在线教育”是否可选 | 按平台要求 | 当前无视频课程，不建议直接选“在线视频课程”而引入不必要的视听资质 |

不建议选择：

- `教育服务 → 在线视频课程`：当前没有视频播放/直播，选了反而需要额外资质。
- `课程销售`、`教育平台`：没有交易、入驻或课程售卖。
- `文娱/资讯`：内容属性是课程配套，不是新闻资讯或娱乐内容。
